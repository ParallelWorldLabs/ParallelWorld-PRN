# ParallelWorld-PRN

基于平行世界（ParallelWorld）的平行契约合同存管仓库，由平行契约插件在各方签署后自动同步与更新，作为合同签署状态的公开凭证记录。

## 仓库说明

- 本仓库存储平行契约合同的同步记录，包含合同文件、各签署方签名及同步索引。
- 固定签约方合同的正文以加密形式存储，仅合同当事方可解密读取；仓库管理员与其他第三方均无法查看内容。
- 持续加入协议为公开文本，任何人均可查阅原文。
- 每份合同具有全局唯一的固定标识，内容一经签署不可变更；任何修改将以新合同形式另行记录。

## 数据完整性

本仓库由插件自动化流程管理，所有内容均经过签名验证后写入，并在每次导入时进行完整性校验。**请勿手动修改仓库文件**——未通过验证的改动会在各方导入时被自动识别并拒绝。

## 使用方式

1. 安装平行契约（PW-Plugin-PRN）插件；
2. 在插件"合同"页选择"从 GitHub 链接导入"，粘贴本仓库中对应合同目录的链接；
3. 核对合同原文后，按插件指引完成签署。
